Hosted PhotoCraft and PdfCraft

PhotoCraft online, free: edit Photoshop files in your browser.

Atelier Cloud hosts the open-source PhotoCraft and PdfCraft editors at one web address. Open a PSD, PSB or PDF without installing anything, and keep each project in a workspace this browser holds, next to the copies you saved and the bucket you send documents to.

The workspace between sessions

A browser editor usually opens a file, edits it and saves it back to disk. The tab holds the work while it is open; after that, the project is whichever download you kept. A workspace keeps the project between sessions, beside the copies you saved.

A project library

Every project gets a workspace in the browser's own storage, under atelier-cloud/. Reload the page, close the tab or open a second tab: the grid still lists it with its document, size and last change.

See what changed before you save

The Changes panel compares the document with the last copy you kept and lists what changed, with counts and sizes. It runs in the browser, so nothing is uploaded first.

A bucket you control

Attach an S3-compatible bucket to one workspace. This browser signs each request with the key you entered and sends the bytes itself, so no document and no credential pass through the server.

PhotoCraft and PdfCraft

A workspace holds the documents for a project, whichever editor they belong to. The file extension decides which editor opens a document, and both editors save into the workspace.

Photos

PhotoCraft

Layered photo editing in its own tab, for PSD, PSB and .pcraft files.

  • Layers, groups and masks, read and written in place.
  • Also opens PNG, JPEG, TIFF, WebP, EXR, HDR, SVG and Krita files.
  • Saves into the workspace without a download step.
PDF

PdfCraft

A PDF workbench inside the workspace page, for PDF jobs you would otherwise do in a desktop application.

  • Read, search and copy text from any PDF.
  • Organize pages, then combine, extract or split documents.
  • Comment, fill interactive forms, and protect a file with a password.
  • Saves into the workspace from the same page.

PhotoCraft and PdfCraft are separate open-source projects by the ArtCraft Team. See credits.

How it works

Four steps, all inside the browser. Documents stay in this browser until you attach a bucket and upload one.

  1. Open a workspace

    Start empty, from a bundled sample, or from a .pcraft or PDF on disk.

  2. Edit in PhotoCraft or PdfCraft

    PhotoCraft opens the document in its own tab. PdfCraft opens inside the workspace page.

  3. Save and review

    File ▸ Save writes the document back to the workspace. The Changes panel shows what changed.

  4. Save a copy

    Download the file, or upload it to your bucket.

Where your files go

A document can sit in three places, and only one of them is ours. The browser's network tab shows the whole path.

This browser

The workspace, its document and the copies you saved. They survive a reload and a second tab, and the browser deletes them when it clears site data.

Your bucket

Documents you upload, in S3-compatible storage you control. Access keys stay in this browser's storage and sign each request locally.

Our server

It serves this page and the editor. It never receives a document and never stores a bucket key.

Without a bucket attached, a workspace exists in one browser and nowhere else. Download the .pcraft to keep a copy outside it.

Alpha

Atelier Cloud is early work, offered as is and with no warranty. There is no server-side backup, and clearing this browser's site data deletes every workspace it holds.

Common questions

What people ask before opening a first workspace.

Is PhotoCraft free to use online?

Yes. PhotoCraft and PdfCraft are open source, and Atelier Cloud is free while it is in alpha. There is no account and no trial to expire.

Can I open PSD files in the browser without Photoshop?

Yes. PhotoCraft opens layered PSD and PSB documents and saves them back, keeping layers, groups and masks. It is a young editor, and its authors describe it as not yet a replacement for daily professional Photoshop work.

Do I have to install anything?

No. Both editors run in a browser tab. Atelier Cloud needs a browser with the Origin Private File System and WebAssembly, which current Chrome, Edge, Firefox and Safari have.

Where are my files stored?

Each project is a workspace in this browser's own storage, so it survives a reload. A document leaves the machine only when you upload it to a bucket you configured, and the server that serves this page never receives one.

Does it work for PDFs too?

Yes. PdfCraft reads, searches, rearranges, combines, splits and annotates PDFs, fills in forms, adds a password, and saves the result into the same workspace.
