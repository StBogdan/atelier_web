PhotoCraft and PdfCraft in the browser

A local workspace, with powerful open-source photo and PDF editors.

Atelier Cloud runs both editors at a web address and gives every project a workspace of its own. The workspace lives in this browser, with your saved work and the bucket you send it to.

To your workspaces See how it works

Nothing to install and no account to make. Free while it is alpha.

Browser editors usually forget the project.

Open a file, edit it, save it back to disk. The tab holds your work while it is open, and after that the project is whichever download you kept. A workspace is a place the project lives between sessions, with the copies you kept beside it.

A library, not a file picker

Every project gets a workspace in the browser's own storage, under atelier-cloud/. Reload the page, close the tab, open a second one: the grid still lists it with its document, size and last change.

See what changed before you save

The Changes panel compares the document with the last copy you kept and lists what changed, with real counts and sizes. No upload, and no guessing.

Your bucket, your keys

Attach an S3-compatible bucket to one workspace. This browser signs each request with the key you entered and sends the bytes itself, so no document and no credential passes through the server.

Two editors, one workspace.

A workspace holds the documents for a project, whichever editor they belong to. The document's extension decides which one opens it, and both save straight back into the workspace.

Photos

PhotoCraft

Layered photo editing in its own tab, on PSD, PSB and .pcraft.

  • Layers, groups and masks, read and written in place.
  • Also opens PNG, JPEG, TIFF, WebP, EXR, HDR, SVG and Krita files.
  • Saves straight back into the workspace, with no download in between.
PDF

PdfCraft

A PDF workbench inside the workspace page, for the jobs you would otherwise open a desktop application for.

  • Read, search and copy text from any PDF.
  • Organize pages, then combine, extract or split documents.
  • Comment, fill interactive forms, and protect a file with a password.
  • Saves straight back into the workspace, from the same page.

PhotoCraft and PdfCraft are separate open-source projects by the ArtCraft Team. See credits.

From an empty workspace to work you can keep.

Four steps, all inside the browser. Nothing is uploaded until you attach a bucket and ask for it.

  1. Open a workspace

    Start empty, from a bundled sample, or from a .pcraft or PDF on disk.

  2. Edit in PhotoCraft or PdfCraft

    PhotoCraft takes the document in its own tab. PdfCraft opens inside the workspace page.

  3. Save and review

    File ▸ Save writes back here. The Changes panel shows what moved.

  4. Save a copy

    Download the file, or upload it to your bucket.

Where your files go.

Three places, and only one of them is ours. You can read the whole path in the browser's network tab.

This browser

The workspace, its document and the copies you saved. They survive a reload and a second tab, and they are cleared when the browser clears site data.

Your bucket

Documents you upload, in S3-compatible storage you control. Access keys stay in this browser's storage and sign each request locally.

Our server

Serves this page and the editor. It never receives a document and never stores a bucket key.

Without a bucket attached, a workspace exists in one browser and nowhere else. Download the .pcraft to keep a copy outside it.

Alpha

Atelier Cloud is early, unfinished work, offered as is and with no warranty. There is no server-side backup, and clearing this browser's site data deletes every workspace it holds.

Your workspaces are in this browser.

The grid lists every project this browser holds. Make a new one from a sample or a file, open it in PhotoCraft or PdfCraft, and save a copy when you are happy with it.
